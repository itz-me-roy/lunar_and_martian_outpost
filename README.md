# lunar_and_martian_outpost
This is the game for student's of age from 7 to 12 years who doesn't know any thing about Outpost's, radiations,.. etc to become a "Junior Astronaut Mission Trainer". It will help them to know basically about what are the things that are facing by astronauts in the Lunar and Martian outpost's. This game built with real NASA datum and NASA API Keys.
